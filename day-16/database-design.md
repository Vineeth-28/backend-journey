## Database Design Mental Model

```text
Entities
   ↓
Tables
   ↓
Columns + Primary Keys
   ↓
Relationships
   ↓
Foreign Keys
   ↓
Normalization
   ↓
Reliable Database Design
```

## Key Takeaways

```text
Schema
→ Blueprint of the database

Primary Key
→ Uniquely identifies a row

Foreign Key
→ Connects related tables

1:1
→ One-to-One

1:N
→ One-to-Many

N:M
→ Many-to-Many

Junction Table
→ Represents a many-to-many relationship

Composite Key
→ Multiple columns together identify a row

Candidate Key
→ Minimal unique identifier

Super Key
→ Any unique identifier

Functional Dependency
→ A determines B

1NF
→ Atomic values

2NF
→ No partial dependency

3NF
→ No transitive dependency
```
