## What I Learned

- JavaScript automatically converts values in some operations.
- Number(), String(), and Boolean() perform explicit conversion.
- == performs type coercion.
- === compares both value and type.
- Truthy and Falsy values affect conditions.

## Backend Usage

- Validating API request data.
- Converting user input.
- Avoiding bugs caused by ==.
- Using === for reliable comparisons.
