# 📖 Concepts Learned

## 📌 Arrays

Arrays are used to store multiple values in a single variable.

Example:

```javascript
const fruits = ["Apple", "Banana", "Orange"];
```

Practiced:

- Creating Arrays
- Accessing Elements
- Updating Elements
- Traversing Arrays using loops

---

## 📌 Array Methods

Methods practiced:

- push()
- pop()
- shift()
- unshift()
- includes()
- indexOf()
- length

---

## 📌 Objects

Objects store data in key-value pairs.

Example:

```javascript
const user = {
    name: "Vineet",
    age: 27,
    role: "Backend Engineer"
};
```

Practiced:

- Accessing properties
- Updating properties
- Adding new properties

---

## 📌 Template Strings

Template strings provide a cleaner way to create dynamic strings.

Example:

```javascript
const name = "Vineet";

console.log(`Hello ${name}`);
```

Advantages:

- Better readability
- Supports variables directly
- Supports expressions inside strings
