# Day 20 — What Happens When You Visit www.google.com?

## Goal

Understand the high-level journey that happens when a client enters a
domain name and communicates with a backend server.

## Topics Covered

- DNS
- Domain names
- IP addresses
- TCP
- TLS
- HTTPS
- HTTP request
- HTTP response
- Client-server communication
- Backend server

## High-Level Flow

```text
Browser
   ↓
Domain Name
   ↓
DNS Lookup
   ↓
IP Address
   ↓
TCP
   ↓
TLS
   ↓
HTTPS
   ↓
HTTP Request
   ↓
Backend Server
   ↓
HTTP Response
   ↓
Browser
